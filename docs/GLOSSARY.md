# Glossary

Add project-specific terms and acronyms as they appear.

| Term | Meaning |
|---|---|
| ADR | A significant decision, alternatives, and consequences |
| Canonical source | The authoritative location for one kind of fact |
| Evidence | An observation/check with enough context to inspect its scope |
| Proposed | Idea, not completed implementation |
| Validating | Research/testing underway |
| Implemented | Feature exists; verification may be incomplete |
| Verified | Defined criteria passed with linked evidence |
| Deferred | Intentionally postponed with a reason |
| Rejected | Not pursued; reasoning preserved |
| Hypothesis | A claim to investigate, not an established fact |
