# Changes & My Review List

Review selected pages, keep your personal reading/questions list, and find changed documentation on later visits.

<!-- READER:CENTER -->

<details markdown>
<summary>How to use this / comparison and storage limits</summary>

On first use there is no previous-visit history. Choose **Create starting baseline** to remember this built catalog. On later visits compare added, changed and removed pages against that baseline.

Marks are stored **only in this browser, under this project's identity**. They do not edit source files, GitHub, or your AI chat. A previously read page that changes is marked for another review. Acknowledging changes does not mark every page as read.

A page introduction is not an automatic diff summary. When supplied, the document author's latest change note is shown separately. This portal does not monitor application code or all conversations.

With JavaScript disabled, read the [Work Log](../control-center/WORK_LOG.md) and [Current State](../CURRENT_STATE.md) directly. Clearing browser data or changing origins/project identity can make personal marks unavailable. A local JSON backup can be exported; this first version has no import or account synchronization.

</details>
