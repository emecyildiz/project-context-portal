# AI Workflow

1. Read current state and the relevant canonical source.
2. Confirm the intended small outcome and scope.
3. Perform authorized work without disturbing unrelated changes.
4. Verify proportionately and record actual outcomes.
5. Update affected documents, state, and work log.
6. Report results, evidence, limitations, and next step.

Source changes refresh the dev website; it does not import all conversations.

## Different assistants, one memory

Common instructions live in AGENTS.md and AI_SETUP.md. CLAUDE.md imports the common contract; other assistants can be explicitly directed to read it. Auto-discovery depends on tool, version, and settings.

An agent in an adjacent application may not read the portal's instructions. Ask the user to authorize portal access and an optional short link in existing application instructions. Never overwrite them.

References checked 2026-10-05: [OpenAI Docs](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [Claude Code](https://code.claude.com/docs/en/memory).

Markdown instructions cannot enforce obedience or bypass permissions. Review evidence; preserve failures and unknowns.
